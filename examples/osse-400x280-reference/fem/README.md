# FEM result

Interior FEM reference sweep: 500–5000 Hz, 12 points per octave, 6 elements per
wavelength. `interactive_report.html` is the standard human-readable result
and plots throat-impedance magnitude normalized by `ρc/Sₜ`.
`responses.npz`, `metrics.csv`, and `mesh_report.json` retain compact numerical
and mesh data.
