# Pre-control-decoupling BEM archive

These documents record BEM studies and planning regimes that preceded the
canonical round control-decoupling study. They are retained for provenance and
for the observations that motivated the current experiment.

They are **not active plans**. In particular, do not use them to:

- schedule remote-domain, uniform-S, adaptive K/N, or coupled Phase 3/4 work;
- restore quarter-step K or sub-unit N refinement;
- restore Coverage Match, Coverage Smoothness, Waist Stability, Window
  Uniformity, finalist-comparison reports, or worst-third-octave ranking;
- include 25-degree, 60-degree, 200 mm, or 500 mm cells in the canonical study;
- treat their `running` fields as live process state; or
- redefine OSSE length by combining or exchanging it with extension.

The `current_bem_*` filenames are preserved because they were generated artifact
names at the time. They are frozen historical snapshots, despite the word
“current.” The archived learning ledger governed the abandoned remote-domain
program and is not authoritative for present candidate selection.

Current documentation begins at [the documentation index](../../README.md) and
the [canonical study plan](../../../examples/control-decoupling/study_plan.md).
